# Contributing to VANA Ayurveda

Thank you for your interest in improving VANA Ayurveda. This project is an early-stage React prototype exploring an approachable digital presentation of Ayurveda concepts.

## Ways to contribute

- Report reproducible bugs and unexpected behaviour.
- Suggest improvements to usability, responsive layouts, and accessibility.
- Improve code readability, component structure, and performance.
- Improve setup instructions and project documentation.
- Suggest educational content improvements, with reliable sources where appropriate.

## Before you start

1. Check the existing issues and pull requests to avoid duplicating work.
2. For a substantial change, open an issue first to discuss the proposed approach.
3. Keep changes focused. Avoid unrelated formatting or dependency updates.
4. Do not add medical claims, diagnosis language, or promises that a product treats or cures a condition.

## Local development

```bash
git clone https://github.com/karanjadav05/vana-ayurveda.git
cd vana-ayurveda
npm install
npm run dev
```

Before submitting a change, run:

```bash
npm run lint
npm run build
```

Please mention if either check cannot be run and include the reason.

## Pull request checklist

- [ ] The change has a clear, focused purpose.
- [ ] The interface remains usable on mobile and desktop where relevant.
- [ ] Interactive elements have clear labels and sensible keyboard behaviour.
- [ ] No secrets, API keys, personal data, or generated build files are included.
- [ ] Documentation is updated when behaviour or setup changes.
- [ ] Lint and production build checks pass, or any limitation is explained.
- [ ] Wellness content is framed as educational and does not make unsupported medical claims.

## Reporting a security issue

Please do not publish exploitable security details in a public issue. Contact the maintainer privately through the contact options on the GitHub profile: https://github.com/karanjadav05.

## Scope and expectations

VANA is a prototype and its structure may evolve. A pull request is not guaranteed to be merged; changes are reviewed for project fit, maintainability, accessibility, and responsible presentation of wellness information.

Thank you for helping make the project better.
